# 📝 Student-Marks-Handler-VB

### [ Freelance Project - 2021 ]

A specialized Windows application built with **VB.NET** to record and manage student grades efficiently. This tool allows educators to log marks, track course performance, and ensure data integrity through a streamlined interface.

---

## 🚀 Main Features

* **Grade Entry System**: Easily add and save student marks for various courses directly into the system.
* **Duplicate Prevention**: Integrated logic to ensure that a grade for the same student and course isn't recorded twice, preventing data errors.
* **Quick Retrieval**: View and filter recorded grades by Student ID or Course ID using optimized **LINQ** queries.
* **Lightweight Storage**: Efficiently manages data using a local flat-file system (`.txt`), making it fast and portable.

---

## 🛠️ Technical Overview

* **Development Platform**: Visual Studio (VB.NET)
* **User Interface**: Windows Forms (WinForms)
* **Data Logic**: LINQ (Language Integrated Query) for filtering and validation.
* **Storage Format**: CSV-style text files for persistence.
